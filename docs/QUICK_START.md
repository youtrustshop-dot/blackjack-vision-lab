# Quick start — 1.0

The first visit offers setup and a four-step guide. **Configure** and **Quick
guide** reopen them. English is the default; Italiano is secondary. Saved rules
stay in the browser. New tables ask whether to reuse them, with a “without asking
again” option.

1. **Match the table.** Decks, S17/H17, payout, surrender, split/double and dealer
   card procedure affect actions and EV. Standard uses the lab defaults;
   hit/stand mode disables doubles, splits and surrender. Insurance remains a
   separate decision when offered, with a decline-policy baseline.
2. **Try Run lab demo.** Its bot acts every four seconds; Pause bot enables manual
   play. The independent observer watches video, including visible controls and
   shoe / round / hand / session labels.
3. **Share screen in Chrome / Edge.** Select the intended screen, window or tab.
   For a full display, select TL/TR/BR/BL table corners and apply calibration. Keep
   the table in place. The browser grant and separate Picture-in-Picture window
   require your clicks. The desktop WebView can hand off to the browser.
4. **Read the large action.** Stable valid hands get legal advice. The ace chip
   shows 1/11, its active value and the alternate total. Expand the advisor for
   base policy, count comparison, EV and uncertainty.

**Add table** creates an independent observer, up to five. One screen grant can
supply several regions; calibrate each explicitly. Each table retains its own
rules and history. Poker / other sources are visual monitors only. More tables
increase work; 500 samples is the multi-table starting setting. Update latency
and sampling uncertainty are visible tradeoffs.

Starting late, restarting observation, changing calibration or saving rules starts
a new observed history. Declare a fresh shoe only when that reset is known. The
lab’s visible session label prevents a new simulation with the same shoe/round
number from merging into an old count. External games need their own observable
reset or a user declaration.

**Image & manual advice** accepts Ctrl+V, drag/drop and file selection. Recognition
supports lab artwork. Confirm player cards and dealer upcard for other designs.
Split context and an optional exposed-card list can be supplied; the list includes
current cards. Image estimates use a conditional pool with earlier history
unknown. One image cannot establish a complete shoe.

**Basic strategy library** covers hard/soft/pair/natural hands and all 550 starting
combinations. **Programs & extensions** separates essentials from optional tools.
The local launcher must stay open; Reconnect handles a lost backend with a
recovery message.

Unreadable, moving or expired video displays a status. Confirm cards or restore
the source before using an action. Outcome probability, classifier confidence,
current-action EV and next-round betting edge are distinct. Analysis and education
only; not financial advice or a winning system.
