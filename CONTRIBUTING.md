# Contributing

Use Python 3.12+ and Node.js 22+. On Windows, run `./setup.ps1`.

```powershell
.venv/Scripts/python.exe -m pytest -q
npm --prefix ui run build
```

Changes to the mathematical core need independent analytic cases or differential
evidence with explicit rules, observable information, EV units and tolerances.
Do not feed hidden cards or the future shoe order into player decisions.
Preserve incomplete-result gates, uncertainty labels and failed experiment reports.

For perception changes, keep sessions separate across train/calibration/test and
verify tracking, count drift and whether the analysis gate admits wrong states.
Report controlled rendering results separately from external photography.
Adapters without measured model runs must remain labelled as unbenchmarked.

Never commit API keys, local environments, generated executables or external
datasets without their licences. Dependencies retain their original licences.

The existing Windows binaries correspond to the original 0.1.0 source hashes
recorded in `release/`. A modified core or UI requires a new tested release.
